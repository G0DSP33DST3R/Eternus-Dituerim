# Eternus Dituerim Quick Guide

This file is a quick-reference guide for using the program. It is intended to help you create, modify, and use characters, items, spells, and attacks, then move into combat.

## 1. Starting a New Game

- Launch the program and open a new campaign or character sheet.
- If the program supports multiple characters, create a new character before adding gear or abilities.
- Save your progress early and often.

## 2. Creating a Character

- Go to the character creation section.
- Enter the character name, class, race, level, and any basic stats.
- Add attributes such as strength, dexterity, intelligence, and vitality if the program tracks them.
- Set defense, health, mana, initiative, and other derived values.
- Confirm the character to save it to your roster.

Tips:
- Keep names clear and unique.
- Use the same naming pattern for all party members.
- Review stats before moving on to abilities and equipment.

## 3. Creating and Managing Items

- Open the item creation or inventory manager.
- Add a new item with a name, type, rarity, description, and value if applicable.
- Assign effects such as damage, armor, healing, bonuses, or restrictions.
- Attach the item to a character from the inventory panel.

Common item types:
- Weapons
- Armor
- Consumables
- Trinkets
- Key items

Use the inventory screen to:
- Equip or unequip items
- Remove items
- Trade or transfer items between characters
- Check item bonuses and penalties

## 4. Creating and Managing Spells

- Open the spell creation section.
- Enter the spell name, school, rank, target type, range, and cost.
- Add a description and effects.
- Set values for damage, healing, buffs, debuffs, or status effects.
- Save the spell so it can be assigned to a character.

When using spells:
- Check mana or resource cost
- Confirm range and target rules
- Review whether the spell affects one target, multiple targets, or the whole battlefield

## 5. Creating and Managing Attacks

- Open the attack creation or combat management menu.
- Create a new attack with a name and attack type.
- Set attack values such as damage, hit chance, crit chance, range, and effects.
- Add conditions such as stun, poison, burn, or knockback if supported.
- Save it and assign it to a character or creature.

Attack examples:
- Melee strike
- Ranged shot
- Area attack
- Spell attack
- Special move

## 6. Manipulating Characters, Items, Spells, and Attacks

Once created, these objects are usually edited through a data panel or list view.

Typical actions:
- Edit existing values
- Duplicate entries for similar creations
- Delete entries you no longer need
- Assign equipment to characters
- Link spells to classes or individuals
- Add attack types to a character sheet

Always verify:
- Stats match the intended build
- Item bonuses stack correctly
- Attack ranges and costs are valid
- Spells are available to the right character

## 7. Combat Flow

Combat usually follows this loop:

1. Start encounter
   - Create or load enemies
   - Place characters in initiative order
   - Begin the battle

2. Determine turn order
   - Check initiative or speed values
   - Resolve turns in order

3. Take actions
   - Attack with a weapon
   - Cast a spell
   - Use an item
   - Defend or reposition

4. Apply effects
   - Damage, healing, buffs, debuffs, and status conditions apply immediately when triggered
   - Check if a target is defeated, stunned, or removed from the fight

5. Update resources
   - Reduce mana, health, cooldowns, or item charges as needed
   - Recalculate derived stats if your program does so automatically

6. End the round
   - Advance to the next actor in initiative order
   - Repeat until all enemies or allies are resolved

## 8. Combat Tips

- Check initiative before acting so you know the order.
- Use attacks and spells that fit the target and situation.
- Keep an eye on health, mana, and status effects.
- Use healing and buffs at the right moment to keep the party alive.
- If the program supports combat logs, review them after each round to catch mistakes.

## 9. Basic Example Workflow

A simple turn might look like this:

- Create a fighter character
- Add a sword item
- Add an attack called "Power Slash"
- Give the fighter a healing spell
- Start combat
- Use the weapon attack on the first turn
- Cast a spell on the next turn
- Use a potion when needed
- Continue until the encounter ends

## 10. Final Reminder

The program is easiest to use when you keep your records organized:
- One character per entry
- One item per record with clear effects
- One spell per record with defined costs and targets
- One attack per record with clear damage and range

If you follow this structure, creating characters and managing combat becomes much faster and more consistent.
