# Eternus Dituerim

Eternus Dituerim is a Python-based application designed to help users organize, retain, and revisit important information in a structured and efficient way. In practical terms, it serves as a personal information management tool: it helps store notes, track records, and keep data accessible over time so that users can reference and manage details without losing context.

The project is intended to provide a reliable workflow for:
- saving and organizing notes or records
- maintaining structured information across sessions
- tracking important details in a consistent and accessible format
- supporting ongoing personal or project-based organization

While the exact feature set may evolve as the project grows, the core purpose is to make important information easier to collect, retain, and revisit.
